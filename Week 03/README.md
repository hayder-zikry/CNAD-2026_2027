# Week 03

Practical 3: "World Greatest Music Library", a REST API in Go that serves song data as JSON. It uses [gorilla/mux](https://github.com/gorilla/mux).

Status: in progress.

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| GET | `/api/v1/welcome` | Welcome message |
| GET | `/api/v1/songs` | List all songs |

## Running

```
cd "Practical 3"
go run .
```

The server runs on http://localhost:5000.
