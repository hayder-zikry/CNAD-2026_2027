# Week 02

Practical 2: Go basics exercises. Each question is its own Go program.

| Question | What it does |
| --- | --- |
| Q1 | Works out vapour pressure (millibars) from a dewpoint temperature in Celsius |
| Q2 | Turns a number into Morse code |
| Q3 | Works out library fines from the number of days overdue |
| Q4 | Analyses monthly rainfall data for 2017 to 2019 |

To run a question:

```
cd "Practical 2_Hayder Zikry/Q1"
go run .
```

`Practical 2.docx` is the worksheet and `Practical 2_Hayder Zikry.zip` is the submission.
